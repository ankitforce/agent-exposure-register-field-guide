# Agent Exposure Register Field Guide

Companion repo for the Substack article: The Agent Exposure Register.

Canonical article URL: https://ankitkumar3514.substack.com/p/agent-exposure-register

This kit helps teams review what an AI agent can reach before trusting it with long-running, connected, or external-action work.

## Start Here

- Read `checklists/exposure-register-checklist.md`.
- Copy `templates/exposure-register.md` for one agent.
- Validate structured records with `schemas/exposure-register.schema.json`.
- Give agents `AGENTS.md` and `agent/tasks.md` when asking them to audit a workflow.

## What This Includes

- A practical review checklist.
- A Markdown register template.
- A JSON schema for structured registers.
- Source notes tying the artifact to public evidence.
- Agent-readable task guidance.

## What This Excludes

- Private incident details.
- Secrets, cookies, tokens, credentials, or local draft state.
- A claim that any one vendor has solved agent governance completely.
